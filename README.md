HAT board for the Radxa Zero 3e featuring an FPGA.

Author: opilitethesmartdev



FPGA Options:

* MAX II

  * Pros

    * readily available
    * altera = quartus = easy to use
    * supports Jam STAPL JTAG
    * KiCad support
  * Cons

    * Low resources
* Gowin GW1NR-LV9 (or maybe something even better)

  * Pros

    * More resources
    * HDMI and MIPI support (useful for stuff)
    * better price/performance
  * Cons

    * awful KiCad models
    * maybe (?) not so good documentation
    * idk about IP Cores
